# Retail Territory Map

Prototype de cartographie interactive destiné à visualiser et filtrer des points de vente par zone, enseigne, format et localisation.

## Statut

Ce dépôt contient actuellement un prototype autonome en HTML/JavaScript.

## Structure

```text
index.html   # application cartographique autonome
```

## Important

Les données métier utilisées par ce type d’outil peuvent être confidentielles. Le dépôt ne doit rester public que si son contenu a été vérifié et ne contient aucune donnée interne, commerciale ou personnelle sensible.
