# Retail Territory Map

Prototype de cartographie interactive destiné à visualiser, filtrer et exporter des points de vente par zone, format et localisation.

## Statut

La branche publique contient uniquement un **jeu de données synthétique de démonstration**. Les données commerciales réelles, affectations de territoire, listes de prospects et informations nominatives ne doivent jamais être versionnées dans un dépôt public.

## Structure

```text
index.html   # prototype autonome HTML/CSS/JavaScript
```

## Utilisation

Ouvrir `index.html` dans un navigateur moderne. Le prototype utilise Leaflet et les tuiles OpenStreetMap pour l’affichage cartographique.

## Données réelles

Toute version utilisant des données métier doit vivre dans un dépôt **privé** ou charger ces données depuis une source locale exclue de Git. Ne pas intégrer de noms d’employés, contacts, notes commerciales, statuts de prospection ou affectations internes directement dans le code public.

Voir `CONTRIBUTING.md` pour les règles de structure, de confidentialité et de contribution.
